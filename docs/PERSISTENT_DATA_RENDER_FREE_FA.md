# نگه‌داشتن دیتا در پلن رایگان Render (بدون از دست رفتن اکانت‌ها و دنیا)

## چرا دیتا پاک می‌شد؟

* Render در پلن **Free** دیسک دائمی (Persistent Disk) ندارد. فایل‌سیستم کانتینر موقتی است.
* هر **دیپلوی جدید** (هر push به گیت‌هاب) و همچنین هر **spin-down** بعد از ~۱۵ دقیقه بی‌کاری،
  یک کانتینر کاملاً تازه می‌سازد ⇒ `voxelcraft.sqlite`, `accounts.json`, `worlds/*.json` همه از بین می‌رفتند.
* «آپدیت زنده بدون ری‌استارت» در Render وجود ندارد؛ راه درست این است که دیتا **بیرون از کانتینر** ذخیره شود.

## راه‌حل (رایگان): آینه‌ی دیتا در Turso

فایل `remote-store.js` همه‌ی فایل‌های حیاتی `DATA_DIR` را در یک دیتابیس رایگان Turso (libSQL) نگه می‌دارد:

* **موقع بالا آمدن سرور** آخرین نسخه را دانلود می‌کند (قبل از این‌که سرور چیزی بخواند).
* **هر ۶۰ ثانیه** فایل‌های تغییرکرده را آپلود می‌کند.
* **موقع SIGTERM** (که Render قبل از دیپلوی و spin-down می‌فرستد) یک آپلود نهایی انجام می‌دهد.

فایل SQLite محلی فقط یک کش است؛ سرور از JSONها آن را دوباره می‌سازد. پس چیزی از دست نمی‌رود.

## راه‌اندازی (۵ دقیقه)

1. در <https://turso.tech> اکانت رایگان بساز (با GitHub).
2. یک دیتابیس بساز (از داشبورد یا CLI):
   ```
   turso db create voxelcraft
   turso db show voxelcraft --url        # libsql://voxelcraft-xxxx.turso.io
   turso db tokens create voxelcraft     # توکن
   ```
3. در Render → سرویس → **Environment** دو متغیر اضافه کن:
   * `TURSO_DATABASE_URL` = همان URL
   * `TURSO_AUTH_TOKEN` = همان توکن
4. Save ⇒ Render خودش سرویس را ری‌استارت می‌کند. در Logs باید ببینی:
   `Durable storage: Turso (ok)`

## ⚠️ خیلی مهم: قبل از اولین دیپلوی، از دیتای فعلی بکاپ بگیر

سرور فعلی روی Render **این کد را ندارد**؛ اولین دیپلوی همه چیز را پاک می‌کند. پس **قبل از push**:

1. برو `https://<your-app>.onrender.com/admin` و توکن ادمین را وارد کن.
2. **DOWNLOAD WORLD** را بزن (فقط این در نسخه‌ی قدیمی موجود است) — دنیا امن می‌شود.
3. اکانت‌ها/کیف‌پول‌ها در نسخه‌ی قدیمی راه خروج ندارند؛ اگر Shell رایگان نداری، متأسفانه قابل بازیابی نیستند.
   (اگر سرویس هنوز با دیسک `/var/data` بالاست، دیتا سر جایش می‌ماند — فقط `DATA_DIR` را روی همان `/var/data` نگه دار.)

بعد از دیپلوی نسخه‌ی جدید:
* در پنل ادمین دکمه‌های **DOWNLOAD FULL BACKUP** / **RESTORE EVERYTHING** / **SYNC TO CLOUD NOW** اضافه شده‌اند.
* از این به بعد قبل از هر تغییر مهم یک Full Backup بگیر؛ همه چیز (اکانت‌ها، کیف‌پول، دفتر کل، همه دنیاها) در یک فایل JSON است.

## اندپوینت‌های جدید (با هدر `x-admin-token`)

| متد | مسیر | کار |
|---|---|---|
| GET | `/api/admin/backup` | دانلود بکاپ کامل |
| POST | `/api/admin/restore` | برگرداندن بکاپ کامل |
| POST | `/api/admin/sync` | آپلود فوری به Turso |

## متغیرهای محیطی

| نام | پیش‌فرض | توضیح |
|---|---|---|
| `TURSO_DATABASE_URL` | – | اگر خالی باشد، سینک خاموش است |
| `TURSO_AUTH_TOKEN` | – | |
| `REMOTE_SYNC_INTERVAL_MS` | `60000` | فاصله‌ی آپلود خودکار |
| `DATA_DIR` | پوشه‌ی پروژه | در `render.yaml` روی `/opt/render/project/data` |
